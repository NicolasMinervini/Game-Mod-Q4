# How to install this mod

NOTE: this mod is only meant to run on Windows. You must also have a copy of Quake 4 installed in order to play it (duh).

1. Download the mod files from this repository. Of all the files in this repository, the compiled mod is stored specifically within the "RiskOfRainMod" folder.
2. Find the file location of Quake 4. The location is dependent on where or how you downloaded the game. The directory you're looking for should contain the folder named "q4base", "q4mp", and the Quake 4 executable among other things.
3. Copy and paste the "RiskOfRainMod" folder into the Quake 4 directory.
4. Run Quake 4. Within the "mods" tab of the main menu, you should find this mod available for selection. Simply load the mod, start a new game, and play!

## (optional) opening the mod directly via a shortcut
1. Create a shortcut to the Quake 4 executable.
2. Right click it and open its properties. Look for the field labeled "Target". It should contain the location of Quake4.exe within quotation marks
3. add " +set fs_game RiskOfRainMod" to the end of the text, making sure to have a space between the last quotation mark and the +. within the Target text box, it should now read *"(YourQuake4FilesLocation)\Quake4.exe" +set fs_game RiskOfRainMod*
4. Running this shortcut should now load Quake 4 directly into the mod.

# Features of this mod
1. All weapons no longer run out of ammunition. Have fun.
2. The Blaster, Machine Gun, Shotgun, and Grenade Launcher have been modified.
   - The blaster automatically shoots so long as the fire button is held down. The charged attack has been removed.
   - The machine gun now has two modes, which can be alternated between via reloading. One mode shoots quickly with a large spread, while the other is far more powerful and accurate but much slower.
   - Hold and release the fire button to shoot with the shotgun. The longer the fire button is held, the less the bullets will spread.
   - The grenade launcher now shoots three impact grenades at a time when the fire button is held down. When the button is released, it will instead fire one or two, depending on when it was interupted.
3. Enemies drop one of five permanent stat-increasing pickups upon death. These effects stack, and the number of each collected is shown on the HUD
   - Health upgrades increase the player's maximum health.
   - Attack speed upgrades increase the rate at which all the player's weapons shoot.
   - Speed upgrades increase the player's movement speed.
   - Jump Height upgrades increase the player's jump height.
   - Leeching upgrades will cause the player to gain health each time they hit an enemy.
